# Chantilly STEM Foundation website draft

Open [index.html](index.html) in a browser to preview the one-page website. It is a standalone draft, not a published Wix site.

## Put it in Wix

For the best Wix result, create a blank one-page site in the Wix Editor and recreate the sections of the draft using native Wix strips/sections and text elements. Use the page's heading and paragraph copy as written. Add anchor links named `mission`, `focus`, `team`, and `get-involved` to match the navigation. Set the page title to "Chantilly STEM Foundation | Building What's Next" and use the description from the HTML page's meta tag. Native content will be easier to edit and index than an embedded page.

For a quick visual preview inside Wix, use **Add Elements > Embed Code > Embed HTML**, paste the contents of [index.html](index.html) into the HTML embed, and size the embed for the whole page in both desktop and mobile layouts. This displays the draft inside an iframe, not as native Wix sections; check the iframe height and links in Wix Preview before publishing.

## Before publishing

- Sign in to the foundation's Wix account to create and publish the site; no Wix account was available in the browser used to prepare this draft.
- Confirm that the foundation can reuse the Team 612 photograph from the [team's website](https://www.chantillyrobotics.org/). Replace the image if permission is not available. The current draft loads it from the team's Wix media URL.
- Confirm the foundation's proposed focus/goal wording with its leadership. The mission wording was provided by the foundation; the 501(c)(3) status and EIN are shown on Charity Navigator.
- Add a foundation-owned contact address and a verified donation link only when available. Charity Navigator currently has donations disabled for this profile, so the draft does not send visitors to a donation checkout.
